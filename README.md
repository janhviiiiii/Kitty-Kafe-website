# Kitty Kafé Website

The **Kitty Kafé** website is a delightful online space that combines the love for coffee and cats while supporting a good cause. It aims to create a warm and inviting experience where coffee enthusiasts and cat lovers can come together to enjoy, engage, and make a difference.

---

## Project Overview

- **Description:**  
  Designed and developed a front-end website that serves multiple purposes, offering a cozy atmosphere where users can explore various features, from browsing the menu to adopting a cat.

- **Technologies Used:**  
  HTML, CSS, JavaScript

---

## Key Features

- **Menu Display:**  
  Features 8+ categories, including coffees, teas, snacks, and more.

- **Cat Adoption Section:**  
  Lists details of 10+ adoptable cats, making it easy for potential adopters to find their furry friends.

- **Reservation Form:**  
  Allows users to book reservations seamlessly.

- **FAQs Page:**  
  Provides answers to common questions, reducing support queries by 50%.

- **About Us Page:**  
  Shares the story behind Kitty Kafé, its mission, and values.

- **Donation Options:**  
  Includes multiple ways to donate, leading to a 30% increase in online donations.

---

## Achievements

- Strengthened front-end development and UX design skills.
- Enhanced user experience, resulting in increased engagement and positive feedback.
- Achieved significant improvements in customer support and online donations.

## Getting Started

To get started with the **Kitty Kafé** website, clone the repository and follow the setup instructions below.

### Installation Instructions

1. **Clone the Repository:**  
   Run the following command in your terminal:
   ```bash
   git clone https://github.com/janhviiiiii/Kitty-Kafe-website.git
   ```

2. **Open the Project in Your Code Editor:**  
   Use your preferred code editor (e.g., Visual Studio Code) and open the cloned project folder.

3. **View the Website Locally:**  
   Open the `index.html` file in your browser to view the website locally.

4. **Make Changes and Customize:**  
   Modify the HTML, CSS, or JavaScript files to customize the website to your preferences.
